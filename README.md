# Quran Premium

Aplikasi Al-Qur'an Premium berbasis Vite dan Capacitor dengan desain hijau emerald dan emas.

## Fitur fondasi
- Beranda dan navigasi bawah
- Daftar 114 surah dari AlQuran Cloud API
- Mushaf Arab dan terjemahan Indonesia
- Daftar 30 juz
- Bookmark ayat dan riwayat bacaan tersimpan lokal
- Jadwal salat dan arah kiblat berbasis lokasi
- Tasbih digital dan doa harian
- Konfigurasi awal Capacitor Android

## Menjalankan
```bash
npm install
npm run dev
```

## Build web
```bash
npm run build
```

Data mushaf diambil secara online dari AlQuran Cloud API. Verifikasi teks, terjemahan, sumber audio, dan perhitungan ibadah wajib dilakukan sebelum rilis publik.
